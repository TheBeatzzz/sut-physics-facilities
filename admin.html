Supabase backend

Shared database, login, and managed image storage.

When Supabase is configured, faculty sign in before managing records. The public page reads only verified public-ready equipment through database policies, while equipment images and faculty profile pictures are stored in the shared photo bucket.

  • Faculty authentication
  • PostgreSQL equipment and facility tables
  • Public read policy for approved records only
  • Photo uploads through Supabase Storage
